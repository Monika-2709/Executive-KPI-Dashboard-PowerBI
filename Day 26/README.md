# Task 26 – Executive KPI Dashboard

## Objective
Create a one-page management dashboard with dynamic filters using Power BI.

## Included
- `Superstore_Executive_KPI_Data.csv` – Power BI-ready Superstore-style dataset
- `PowerBI_DAX_Measures.txt` – KPI and supporting DAX measures
- `KPI_Definitions.txt` – KPI definitions and recommended slicers/visuals
- `PowerBI_Dashboard_Guide.txt` – one-page layout and build instructions
- `Executive_KPI_Dashboard_Report.pdf` – task report
- `dashboard_preview.png` – visual reference for the intended one-page layout

## Main KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value

## Recommended slicers
Year, Region, Category, Segment.

## Note
A `.pbix` file is not generated here because Power BI Desktop is required to author and save the native Power BI report. The supplied CSV, DAX, definitions, layout and report are ready to build the dashboard directly in Power BI.
